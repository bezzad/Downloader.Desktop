Take over browser downloads?

When this is on, downloads you start in the browser are handed to the Downloader app instead: the browser's own download is cancelled and the app fetches the file, with the page's sign-in details so restricted files keep working.

That is what the new downloads permission is for. It lets the extension see a download the browser starts and cancel it. Nothing about your downloads leaves your machine — the link is handed to the app over a loopback connection on your own computer, and the permission goes unused while this setting is off.

If the app isn't running, the browser downloads the file as usual. Taking over never costs you a file.

Off by default. When off, nothing below applies and the browser downloads normally.

Where downloads are saved

Prefilled with the folder the app is set to use. Edit it and every download the extension sends goes there, so the app doesn't ask. It must be an absolute path on the machine running the app — the browser can't offer a folder picker for one. Leave it empty to let the app decide.

What to take over

One extension per line, or comma-separated. If a download isn't being taken over, this is almost always why — add its extension here.

Files whose size the browser hasn't determined yet are still taken over.

Sites to leave alone

One site per line. Subdomains are covered too, and this applies to the page a download came from as well as the file's own host.

Saved

Running another download manager that also intercepts downloads alongside this one is not supported — whichever extension reacts first wins.
